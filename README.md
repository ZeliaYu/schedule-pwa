# 排班管理 PWA

显示每日排班、每个人的加班与欠班，支持上传 Excel 排班表自动累计。

**在线地址：<https://zeliaYu.github.io/schedule-pwa/>**

纯前端应用，无后端、无数据库服务。数据保存在浏览器的本地存储里，
可安装到桌面 / 手机主屏幕，**支持离线使用**。

> ⚠️ 数据只存在**当前浏览器**。换设备、换浏览器或清理浏览数据后看不到原数据，
> 请用「人员 → 导出备份」迁移。

## 怎么用

### 1. 打开

电脑或手机浏览器访问 <https://zeliaYu.github.io/schedule-pwa/>。

手机建议「添加到主屏幕」，之后像 App 一样点开即用，断网也能看：

- **iPhone（Safari）**：分享按钮 → 添加到主屏幕
- **Android（Chrome）**：右上角菜单 → 添加到主屏幕 / 安装应用

### 2. 导入排班表

点右上角 **导入** 图标，选 Excel 文件。上传后先预览解析结果，
确认「班次映射」再点下一步写入。

也可以先在「人员」页手动添加人员和班次。

### 3. 每天排班

在「月排班」页点格子选班次，一天可以排多个班次。
统计页会实时算出每人的加班和欠班。

### 4. 换设备 / 备份

**人员 → 导出备份（JSON）** 下载数据文件，在新设备上
**人员 → 从备份恢复** 选该文件即可。

> 备份文件包含全部人员与排班，注意妥善保管，不要随意分享。

## 功能

| 页面 | 说明 |
|---|---|
| **统计** | 累计加班/欠班、每人发散条形图（右加班/左欠班）、月度趋势、人员×日期热力图、表格视图、导出 CSV |
| **月排班** | 月历矩阵，点格子排班（一天可多班次）；批量选择；标记单日工作日/休息日；区间复制；**拖动姓名行调整顺序**；**按人隐藏（离职人员）** |
| **今日** | 按班次分栏列出当天人员，附每日出勤核对 |
| **人员** | 人员与应出勤口径、班次与记班系数、统计起点、备份/恢复、导入 |

### 默认工作日

默认**周一至周五**上班，周六周日休息（可在「人员 → 统计口径」改成任意组合，
也可在月排班页对单日覆盖）。

### 隐藏离职人员

月排班工具栏的 **人员** 按钮可打开人员列表：

- 取消勾选 → 该人从月排班、统计、热力图里隐藏（**排班记录保留**，随时可勾回来）
- 拖动 ⠿ 或在月排班里直接拖姓名行 → 调整显示顺序，顺序对所有视图生效

统计页在存在隐藏人员时会显示「包含已隐藏 (N)」按钮，可临时查看全部。

## Excel 导入

自动识别的四种版式（示例见 [samples/](samples/)）：

1. **人员行矩阵**（最常见）：`工号 | 姓名 | 班组 | 1日 | 2日 | …`
2. **人员列矩阵**：`日期 | 张三 | 李四 | …`，每行一天
3. **明细长表**：`日期 | 工号 | 姓名 | 班组 | 班次`，每行一条记录
4. **按日分块**（现场班表常见）：每天一个小表，日期只在块首

   ```
   2026.11.05 | 周四 | 姓名   | 班次            | 工作内容
                     | 凌丽   | 08：00-生产结束 | 理瓶
                     | 倪财豪 | 请假            | /
   ```

处理规则：

- 休息类标记（`休`/`休息`/`公休`/`调休`/空白/`/`/`OFF` 等）自动跳过
- 表头写 `2026年11月`、`2026-11` 时自动补全年月；按日分块版式直接读每块日期
- 单元格里写 `白班/夜班`、`白+中` 会拆成多个班次
- **时间段自动折算班数**：8 小时 = 1 班（四舍五入到 0.5 班）
  - `08:00-16:00` → 1 班，`16:00-08:00` → 2 班，`08:00-12:00` → 0.5 班，`08:00-生产结束` → 1 班
  - 折算结果落到「白班 / 半班 / 一点五班 / 连班」，可在下拉里改成别的班次
- 与已有班次同名的标记直接用；不认识的标记需手动选择或「忽略」
- 未匹配的人员可按工号匹配已有人员，否则自动新建

### 历史数据：统计起点

现场表往往**只记录当天上班的人**，没上班的人不会出现。直接拿历史表算
「应出勤」会产生大量虚假欠班。做法：

1. 导入历史表，只用来累计「每人已经上了多少班」；
2. 在 **人员 → 统计口径 → 统计起点** 设为开始用 App 排班的那天；
3. 起点之前的记录只计入「历史累计」，不计应出勤；从起点起正常计算加班/欠班。

统计页在设置起点后会同时显示「本期已出勤」和「历史另计」。

## 加班与欠班怎么算

```
已出勤   = Σ 排班记班系数 + 手工「补出勤」
本期差额 = （已出勤 − 统计起点前的出勤）− 应出勤
最终净值 = 本期差额 + 手工加班 + 手工欠班
加班     = max(0, 最终净值)
欠班     = max(0, −最终净值)
累计已上 = 统计起点前的出勤 + 本期出勤
```

- **应出勤**：统计区间内的工作日天数（每人每天 1 班），只算到今天为止；
  也可给单人设「固定月度定额」，跨月区间按自然月折算。
- **工作日**：默认周一至周五（人员页可改），单日可在月排班页覆盖。
- **记班系数**：班次按权重计班（半班 = 0.5），所以数值可为 0.5 的倍数。
- **手工调整**（统计页点人名或表格「调整」）：
  - 加班：直接加净值（顶班、延时）
  - 欠班：直接减净值（早退、临时调休）
  - 补出勤：计入已出勤，可抵消欠班

## 部署（维护者）

仓库 **Settings → Pages**：

- Source：`Deploy from a branch`
- Branch：`main`，目录：**`/docs`**

推送 `main` 后自动构建，约 1~2 分钟生效。

> 私有仓库开启 Pages 需要 GitHub Pro；免费账号只能对公开仓库启用。
> 本仓库不含任何真实排班数据，公开是安全的。

## 测试（开发）

需要 Node.js：

```bash
node tests/stats_vs_python.js   # 统计计算 38 项
node tests/parse_vs_python.js   # 解析/导入 28 项
```

统计与解析逻辑最初由 Python 后端实现，移植到浏览器后与当时的实现逐项对照，
结果完全一致（`tests/*.json` 为基准数据）。这两个文件名保留了历史命名。

## 注意

- **单机数据**：不同浏览器 / 设备之间不共享，需要迁移就导出 / 导入备份。
- 无痕 / 隐私模式可能禁止本地存储，应用会提示无法初始化。
- 请勿用「双击 index.html」的方式打开，浏览器会限制本地存储与离线缓存。
- 首次访问后请等页面完全加载，再「添加到主屏幕」，否则离线缓存可能不完整。
