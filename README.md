# 排班管理 PWA

显示每日排班、每个人的加班与欠班，支持上传 Excel 排班表自动累计。

**在线地址：<https://zeliaYu.github.io/schedule-pwa/>**

纯前端应用，无后端、无数据库服务。数据保存在浏览器的本地存储里，
可安装到桌面 / 手机主屏幕，**支持离线使用**。

> ⚠️ 数据只存在**当前浏览器**。换设备、换浏览器或清理浏览数据后看不到原数据，
> 请用「人员 → 导出备份」迁移。

## 怎么用

### 1. 打开

电脑或手机浏览器访问 <https://zeliaYu.github.io/schedule-pwa/>。

手机建议「添加到主屏幕」，之后像 App 一样点开即用，断网也能看：

- **iPhone（Safari）**：分享按钮 → 添加到主屏幕
- **Android（Chrome）**：右上角菜单 → 添加到主屏幕 / 安装应用

### 2. 导入排班表

点右上角 **导入** 图标，选 Excel 文件。上传后先预览解析结果，
确认每个标记折算成几小时，再点下一步写入。

也可以先在「人员」页手动添加人员。

### 3. 每天排班

在「月排班」页点格子，填 **开始时间 / 结束时间 / 工作内容**。
改了起止时间，工时会自动按时间差算，也可以直接手改（比如中间休息要扣掉）。
一天可以排多条（上午一班、晚上又顶一班）。统计页会实时算出每人的加班和欠班。

排完后打开 **今日** 页，就是一张可以直接发到群里的排班表（点 **导出图片** 下载 PNG）。

**批量排班**：今日页右上角「批量排班」可以一次选多个人，统一设置时段、工时和工作内容。
当天已有排班的人会标「已有」，默认不勾选；点「只选还没排的」一键选出剩下的人。

> **托班怎么办**：点那人当天的格子，把结束时间往后改（或直接把工时改大），保存即生效。
> 格子会显示成「3 段 · 12.5h」。

### 4. 换设备 / 备份

**人员 → 导出备份（JSON）** 下载数据文件，在新设备上
**人员 → 从备份恢复** 选该文件即可。

> 备份文件包含全部人员与排班，注意妥善保管，不要随意分享。

### 5. 清空重来

**人员 → 数据 → 清除所有记录**：删除本机全部人员、排班、手工调整与设置，
恢复到初始状态。

为避免误触，需要先在输入框里手动输入「清除」，**永久清除** 按钮才会变为可点。
删除前可先点弹窗里的「先导出备份」，之后随时能从备份恢复。

> 此操作不可撤销。只删掉个别人请用人员列表里的「移除」。

## 功能

| 页面 | 说明 |
|---|---|
| **统计** | 累计加班/欠班（小时）、每人发散条形图（右加班/左欠班）、月度趋势、人员×日期工时热力图、表格视图、导出 CSV |
| **月排班** | 月历矩阵，点格子填时间段/工时/工作内容（一天可多条）；批量填入工时；标记单日工作日/休息日；区间复制；**拖动姓名行调整顺序**；**按人隐藏（离职人员）** |
| **今日** | 排班看板（按时段分组，姓名 + 工作内容一目了然）、**一键导出图片发群**、批量排班、调休 / 请假标记、出勤核对 |
| **人员** | 人员与应出勤口径（每天标准工时）、统计起点、**常用工作内容**、备份/恢复、导入、清除所有记录 |

### 今日页：截图或导出图片发群

打开「今日」，看到的就是一张可以发给班组的排班表：

```
11月3日 周二
出勤 6 人   合计 48 小时   共 2 个时段
────────────────────────────────
08:00 – 16:00   8 小时              4 人
  张三  理瓶        李四  灌装
  王五  压塞        赵六  贴标
16:00 – 24:00   8 小时              2 人
  钱七  灌装        孙八  包装
────────────────────────────────
调休  周九
请假  吴十
```

- 按时间段分组，同一班的人排在一起，姓名和负责的工作内容左右对齐
- 点任意一个人可以直接改他那天的时段
- **批量排班**：今日页右上角，一次勾选多人统一排班，可给某人单独指定不同的工作内容
- **工作内容直接选**：排班时点胶囊选，不用每次打字；缺的在弹窗里「+ 新增」即可
  （也可以在「人员 → 工作内容」里统一添加 / 删除）
- 底部列出 **调休** 和 **请假** 两类，方便大家确认自己今天要不要来
- 点底部的人名可在「调休 / 请假」之间切换；批量排班里也能一键给多人标记
- **导出图片**：生成 2 倍清晰度的 PNG，直接下载/保存，发微信群不会糊
- 也可以直接手机截屏，看板就是按截图设计的（浅色底、大字、无按钮干扰）

### 全部按小时算

应用里没有「白班 / 夜班」这类固定班次，每个人的出勤一律折算成 **小时**：

- 排班时填时间段和工时；改了起止时间工时会自动重算，也可手改
- 应出勤 = 工作日天数 × 每人每天标准工时（默认 8，可在人员页改，也能给单个人设不同值）
- 休息日上班的工时单独计入加班
- 加班 / 欠班 / 净值全部是小时数

### 默认工作日

默认**周一至周五**上班，周六周日休息（可在「人员 → 统计口径」改成任意组合，
也可在月排班页对单日覆盖）。

### 隐藏离职人员

月排班工具栏的 **人员** 按钮可打开人员列表：

- 取消勾选 → 该人从月排班、统计、热力图里隐藏（**排班记录保留**，随时可勾回来）
- 拖动 ⠿ 或在月排班里直接拖姓名行 → 调整显示顺序，顺序对所有视图生效

统计页在存在隐藏人员时会显示「包含已隐藏 (N)」按钮，可临时查看全部。

## Excel 导入

自动识别的四种版式（示例见 [samples/](samples/)）：

1. **人员行矩阵**（最常见）：`工号 | 姓名 | 班组 | 1日 | 2日 | …`
2. **人员列矩阵**：`日期 | 张三 | 李四 | …`，每行一天
3. **明细长表**：`日期 | 工号 | 姓名 | 班组 | 班次`，每行一条记录
4. **按日分块**（现场班表常见）：每天一个小表，日期只在块首

   ```
   2026.11.05 | 周四 | 姓名   | 班次            | 工作内容
                     | 凌丽   | 08：00-生产结束 | 理瓶
                     | 倪财豪 | 请假            | /
   ```

处理规则：

- 休息类标记（`休`/`休息`/`公休`/`调休`/空白/`/`/`OFF` 等）自动跳过
- 表头写 `2026年11月`、`2026-11` 时自动补全年月；按日分块版式直接读每块日期
- 单元格里写 `白班/夜班`、`白+中` 会拆成多条记录
- **时间段自动折算工时**（8 小时 = 一个标准工作日）
  - `08:00-16:00` → 8h，`16:00-08:00` → 16h，`08:00-12:00` → 4h，`08:00-生产结束` → 8h
  - 只写班次名时按常识估：`白班`/`中班`/`夜班` → 8h，`半班` → 4h，`连班` → 16h
  - 所有估算值都能在映射页直接改；起止时间会一并存入，之后可在月排班里调整
- 认不出的标记需手动填工时，或勾「忽略」
- 未匹配的人员可按工号匹配已有人员，否则自动新建
- **可只导入部分人员**：映射页有人员勾选列表，取消勾选的人不会导入
  （表里有很多已离职的人时用这个），支持全选 / 全不选

### 历史数据：统计起点

现场表往往**只记录当天上班的人**，没上班的人不会出现。直接拿历史表算
「应出勤」会产生大量虚假欠班。做法：

1. 导入历史表，只用来累计「每人已经上了多少小时」；
2. 在 **人员 → 统计口径 → 统计起点** 设为开始用 App 排班的那天；
3. 起点之前的记录只计入「历史累计」，不计应出勤；从起点起正常计算加班/欠班。

统计页在设置起点后会同时显示「本期已出勤」和「历史另计」。

## 加班与欠班怎么算

单位统一为 **小时**：

```
已出勤     = Σ 工作日排班工时 + 手工「补出勤」
休息日加班 = Σ 休息日的排班工时
本期差额   = 已出勤 − 应出勤
最终净值   = 本期差额 + 休息日加班 + 手工加班 + 手工欠班
加班       = max(0, 最终净值)
欠班       = max(0, −最终净值)
累计已上   = 统计起点前的工时 + 本期出勤 + 休息日加班
```

- **应出勤**：统计区间内的工作日天数 × 每人每天标准工时，只算到今天为止；
  也可给单人设「固定月度工时定额」，跨月区间按自然月折算。
- **休息日上班算加班**：在周六周日（或手动标记的休息日）排的班，按工时直接计入加班，
  不计入「已出勤」（避免与应出勤重复计算）。表格里显示为「+7 含休息日 4h」。
- **请假不算欠班**：标了「请假」的工作日会从该人的应出勤里扣掉（每天扣一个标准工时），
  所以不会因为请假产生欠班。「调休」照常按缺勤计算。
- **工作日**：默认周一至周五（人员页可改），单日可在月排班页覆盖。
- **手工调整**（统计页点人名或表格「调整」）：
  - 加班：直接加净值（顶班、延时）
  - 欠班：直接减净值（早退、临时调休）
  - 补出勤：计入已出勤，可抵消欠班

> **从旧版本升级**：以前的数据（班次 + 记班系数）会自动换算成工时，
> 1 班 = 8 小时；旧班次名保留在备注里。不需要手动迁移。

## 测试（开发）

需要 Node.js：

```bash
node tests/stats_vs_python.js   # 统计计算 40 项
node tests/parse_vs_python.js   # 解析/导入 37 项
node tests/migrate_v1_v2.js     # 旧数据（班次）迁移到工时 11 项
python tests/leave_check.py     # 调休 / 请假口径 8 项 + 与 Python 结果对照
```

统计逻辑最早由 Python 后端实现，现在改用 `tests/gen_expected.py`
（一份独立的 Python 实现）生成基准值，JS 版本与之逐项对照。
基准把「今天」固定为 2026-11-30，所以结果不会随运行日期漂移。
改了统计口径后，重跑 `python tests/gen_expected.py` 再跑上面的 Node 测试。

## 注意
