# 排班管理 PWA

显示每日排班、每个人的加班与欠班，支持上传 Excel 排班表自动累计。

- 后端：FastAPI + SQLite（conda **NAFNet** 环境）
- 前端：原生 JS 单页 + PWA（可安装到桌面/手机，支持离线只读）
- 部署：本机运行，数据存 `data/schedule.db`；支持导出/导入 JSON 备份

## 快速开始

```bat
双击  启动.bat
```

或手动：

```bash
D:/Anaconda3/envs/NAFNet/python.exe backend/app.py
```

浏览器打开 <http://localhost:8765>。同一局域网内，手机用启动窗口里显示的
`http://<本机IP>:8765` 访问，可「添加到主屏幕」当作 App 使用。

环境变量（可选）：`SCHEDULE_HOST`、`SCHEDULE_PORT`、`SCHEDULE_DB`。

## 功能

| 页面 | 说明 |
|---|---|
| **统计** | 累计加班/欠班、每人发散条形图（右加班/左欠班）、月度趋势、人员×日期排班热力图、表格视图 |
| **月排班** | 月历矩阵，点格子排班（可一天多班次）；批量选择；标记单日工作日/休息日；区间复制 |

| **人员** | 人员与应出勤口径、班次与记班系数、默认工作日、备份/恢复、导入 |

## Excel 导入

上传后先**预览解析结果**，确认「班次映射」再写入，不会直接改库。

自动识别的四种版式（示例见 [samples/](samples/)）：

1. **人员行矩阵**（最常见）：`工号 | 姓名 | 班组 | 1日 | 2日 | …`
2. **人员列矩阵**：`日期 | 张三 | 李四 | …`，每行一天
3. **明细长表**：`日期 | 工号 | 姓名 | 班组 | 班次`，每行一条记录
4. **按日分块**（现场班表常见）：每天一个小表，日期只在块首
   ```
   2026.11.05 | 周四 | 姓名   | 班次            | 工作内容
                     | 凌丽   | 08：00-生产结束 | 理瓶
                     | 倪财豪 | 请假            | /
   ```

处理规则：

- 休息类标记（`休`/`休息`/`公休`/`调休`/`空白`/`/`/`OFF` 等）自动跳过
- 表头写 `2026年11月`、`2026-11` 时会自动补全年月；按日分块版式直接读每块日期
- 单元格里写 `白班/夜班`、`白+中` 会拆成多个班次
- **时间段自动折算班数**：8 小时 = 1 班（四舍五入到 0.5 班）
  - `08:00-16:00` → 1 班，`16:00-08:00` → 2 班，`08:00-12:00` → 0.5 班，`08:00-生产结束` → 1 班
  - 折算结果落到「白班 / 半班 / 一点五班 / 连班」，可在下拉里改成别的班次
- 与已有班次同名的标记直接用；不认识的标记需手动选择或「忽略」
- 未匹配的人员可按工号匹配已有人员，否则自动新建

### 清洗历史数据：统计起点

现场表往往**只记录当天上班的人**，没上班的人不会出现。直接拿历史表算
「应出勤」会产生大量虚假欠班。做法是：

1. 把历史表导入，只用来累计「每人已经上了多少班」；
2. 在 **人员 → 统计口径 → 统计起点** 设为启用 App 排班的当天；
3. 起点之前的记录只计入「历史累计」，不计应出勤；从起点起正常计算加班/欠班。

统计页在设置起点后会同时显示「本期已出勤」和「历史另计」。每人的「累计已上」
= 历史累计 + 本期出勤，随时可查。

导入选项：覆盖已有排班 / 自动创建人员 / 自动创建新班次。

## 加班与欠班怎么算

每人的净值：

```
已出勤   = Σ 排班记班系数 + 手工「补出勤」
本期差额 = （已出勤 − 统计起点前的出勤）− 应出勤
最终净值 = 本期差额 + 手工加班 + 手工欠班
加班     = max(0, 最终净值)
欠班     = max(0, −最终净值)
累计已上 = 统计起点前的出勤 + 本期出勤
```

- **应出勤**：默认 = 统计区间内的工作日天数（每人每天 1 班）；可给单人设「固定月度定额」，
  跨月区间按自然月折算。
- **工作日**：默认周一至周六（人员页可改），单日可在月排班页「编辑工作日」覆盖。
- **记班系数**：班次可按权重计班（半班 = 0.5），所以数值可以是 0.5 的倍数。
- **手工调整**（统计页点人名或表格「调整」）：
  - 加班：直接加净值（顶班、延时）
  - 欠班：直接减净值（早退、临时调休）
  - 补出勤：计入已出勤，可抵消欠班

## 接口速览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/bootstrap` | 人员 + 班次 + 设置 |
| GET | `/api/schedule?date_from=&date_to=` | 区间排班 |
| POST | `/api/schedule` | 设置单人单日单班次 |
| DELETE | `/api/schedule?date=&employee_id=&shift_code=` | 取消排班 |
| POST | `/api/schedule/bulk` | 批量设置/清除 |
| GET | `/api/stats?date_from=&date_to=` | 区间统计 |
| GET | `/api/stats/monthly` · `/daily` · `/heatmap` | 趋势 / 每日 / 热力图 |
| POST | `/api/adjustments` | 手工加班/欠班/补出勤 |
| PUT | `/api/calendar` | 覆盖单日工作日 |
| PUT | `/api/settings` | 工作日规则、统计起点 |
| POST | `/api/import/preview` | 上传 Excel 返回解析结果 |
| POST | `/api/import/commit` | 按映射写入 |
| GET/POST | `/api/backup` · `/api/restore` | 备份 / 恢复 |

## 注意

- 单机版：多个浏览器同时改会互相覆盖，适合一人维护、多人查看。
- 备份文件包含全部人员与排班，可换机恢复。
- 浏览器离线时只读（读最后一次缓存）；写操作需要连上服务。
